## Project Overview
This application allows users to compare and analyze share prices over time. Users can:
- Fetch daily price information for stock symbols
- Store price data locally for offline access
- Display and compare share price graphs for multiple companies

## Technology Stack
- **Language**: Java
- **Database**: SQLite / JSON
- **Data Source**: Yahoo Finance API (or similar)
- **Architecture**: Clean Architecture, SOA principles
